# 名詞表

最後更新：2026-10-01

| 名詞 | 本專案定義 |
|---|---|
| 包網 | 提供玩家前台、會員、點數或遊戲整合的平台商戶。 |
| 商戶／下游 | 串接本平台建立付款訂單的包網或企業客戶。 |
| 本平台 | 本專案要開發的信用卡渠道與代理結算管理系統。 |
| 上游／通道 | 實際提供信用卡授權、3DS、付款結果與結算資訊的金流服務方。 |
| 玩家／消費者 | 在包網前台刷卡付款的人，不是本平台會員。 |
| 商戶單號 | 商戶建立訂單時提供的唯一編號。 |
| 平台單號 | 本平台建立的唯一訂單編號。 |
| 上游單號 | 上游信用卡金流回傳的交易編號。 |
| 上游結算 | 上游確認此筆信用卡款項可進入商戶結算。 |
| USDT 下發 | 財務依已結算訂單計算並人工轉付 USDT 給商戶。 |
| 子帳號 | 代理建立給業務、中人或股東使用的查帳登入，不是下一層代理。 |
| 消費者手續費 | 額外向刷卡消費者收取的費用。 |
| 商戶端手續費 | 結算行或平台向商戶收取的單筆費用。 |
| 沖正 | 上游撤銷或反轉原交易結果的事件，不應直接刪除原交易。 |
