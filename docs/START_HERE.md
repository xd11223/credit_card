# 專案接續入口

最後更新：2026-10-02（Asia/Taipei）

## 一句話定位

本系統是介於包網商戶與上游信用卡金流之間的渠道管理平台，負責訂單轉送、付款狀態同步、商戶結算、人工 USDT 下發紀錄，以及多層代理佣金帳務。

## 新裝置或新對話怎麼開始

確認已經用 Codex 開啟本專案資料夾後，只要對 AI 說：

> 讀取

結束工作時只要說：

> 儲存

兩個快捷指令的完整行為定義在專案根目錄的 `AGENTS.md`。

## 目前最重要的認知

- 包網商戶是下游；信用卡收單／金流公司是上游。
- 已確認包網先呼叫本平台建立訂單，本平台再送往信用卡渠道；上游完成授權後 callback 本平台，本平台再 callback 包網。
- 玩家不是本系統會員；玩家餘額與遊戲點數由包網管理。
- USDT 不設資金池、不查鏈上餘額，也不替玩家儲值或提領。
- USDT 只在商戶結算時由財務人工下發，系統負責計算與留存紀錄。
- 付款、上游結算、爭議、USDT 下發與風控必須使用不同狀態欄位。
- 代理階層與代理子帳號是不同概念。

## 接下來要做什麼

先確認 `docs/SPECIFICATION.md` 中的渠道成本基數、商戶分攤費用、換匯、退款拒付及代理價差規則，再取得上下游 API 文件，才能凍結資料庫與 API 規格。
