# 專案接續入口

最後更新：2026-10-01（Asia/Taipei）

## 一句話定位

本系統是介於包網商戶與上游信用卡金流之間的渠道管理平台，負責訂單轉送、付款狀態同步、商戶結算、人工 USDT 下發紀錄，以及多層代理佣金帳務。

## 新裝置或新對話怎麼開始

請對 AI 說：

> 請先閱讀 `AGENTS.md`、`docs/START_HERE.md` 與 `docs/CURRENT_STATUS.md`，再接續這個專案。涉及產品規則時，也請查閱 `docs/REQUIREMENTS.md`、`docs/DECISIONS.md` 和 `docs/OPEN_QUESTIONS.md`。

## 目前最重要的認知

- 包網商戶是下游；信用卡收單／金流公司是上游。
- 預期流程是包網先呼叫本平台建立訂單，上游信用卡完成授權後 callback 本平台，本平台再 callback 包網。
- 上述呼叫方向仍待取得實際 API 文件確認。
- 玩家不是本系統會員；玩家餘額與遊戲點數由包網管理。
- USDT 不設資金池、不查鏈上餘額，也不替玩家儲值或提領。
- USDT 只在商戶結算時由財務人工下發，系統負責計算與留存紀錄。
- 付款、上游結算、爭議、USDT 下發與風控必須使用不同狀態欄位。
- 代理階層與代理子帳號是不同概念。

## 接下來要做什麼

先取得或確認實際串接流程，尤其是誰建立訂單、誰接收 callback、上游與包網各自提供哪些欄位。接著才能完成正式 PRD、狀態機、帳務公式、資料庫與 API 規格。
