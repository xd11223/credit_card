# 專案背景與邊界

最後更新：2026-10-01

## 背景

專案預計服務包網、獨立站或其他支付商戶。第一階段只處理信用卡渠道，其他網銀、超商及電子支付留到後續。

平台位於兩端之間：

```text
玩家 → 包網商戶 → 本平台 → 上游信用卡金流
                    ↑              ↓
                    └── 付款結果 ──┘
```

付款成功後，本平台通知包網，由包網自行替玩家加分。本平台不管理玩家帳號或點數。

## 系統責任

- 商戶與 API 憑證管理。
- 商戶可用信用卡通道設定。
- 建立、查詢與追蹤付款訂單。
- 接收上游付款結果並通知包網。
- 保存上游、平台與商戶三組單號。
- 管理上游結算狀態與問題款項。
- 建立 USDT 商戶下發批次。
- 計算多層代理佣金。
- 權限、審批、稽核與報表。

## 非第一階段範圍

- 玩家會員系統。
- 玩家點數或餘額帳本。
- 玩家 USDT 儲值或提領。
- USDT 資金池。
- 鏈上餘額查詢或自動出款。
- 固定綁定商戶錢包。
- 即時交易所或 XE 匯率串接。
- 非信用卡付款方式。

## 主要參與者

- 總管理：平台最高管理權限。
- 營運／客服／財務／風控：建議拆成不同角色。
- 代理：最多幾層仍待正式確認，目前討論傾向三層。
- 代理子帳號：代理開給業務、中人或股東的查帳帳號，不等於下一層代理。
- 商戶：包網或其他串接本平台 API 的企業客戶。
- 玩家：在包網端發起付款的持卡人，不是本平台會員。
- 上游信用卡金流：實際進行信用卡授權、3DS 與交易結果回傳的服務方。
