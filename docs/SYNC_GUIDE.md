# 跨裝置同步指南

最後更新：2026-10-01

## 核心原則

對話本身與專案檔案是兩件事：

- 使用同一帳號和同一對話，可以保留該對話的歷史。
- 換成新對話或不同工作環境時，不應依賴聊天記憶；以這個資料夾內的文件作為正式專案記憶。
- 本機資料夾不會自動出現在另一台電腦或手機，必須另外使用 Git 私有儲存庫或可靠的檔案同步服務。

## 建議方案：私人 Git 儲存庫

1. 將此資料夾建立成 Git repository。
2. 建立私人遠端儲存庫。
3. 家中電腦與公司筆電各自 clone。
4. 每次開始前先取得最新版本。
5. 每次結束後更新 `CURRENT_STATUS.md`，提交並推送。
6. 手機可透過遠端儲存庫 App 閱讀 Markdown、補充需求或查看目前狀態。

建議每次工作前後的操作概念：

```text
開始前：同步最新版本
工作中：更新需求、決策、程式與目前狀態
結束後：提交並推送
```

不要把同一個 Git 工作目錄直接放在多台電腦同時同步編輯，否則容易產生衝突。每台電腦各自 clone 通常更穩定。

## 替代方案：雲端硬碟

也可以用 OneDrive、Google Drive 或其他同步資料夾，但同一檔案在兩台裝置同時編輯時可能產生衝突副本。若專案將包含程式碼，仍建議使用 Git。

## 新對話提示詞

```text
請先閱讀 AGENTS.md、docs/START_HERE.md 與 docs/CURRENT_STATUS.md，
再根據 docs/REQUIREMENTS.md、docs/DECISIONS.md 和
docs/OPEN_QUESTIONS.md 接續信用卡渠道專案。
```

## 不應同步到儲存庫的資料

- 正式環境密碼及 API Key。
- 完整信用卡號、CVV、PIN。
- 錢包私鑰或助記詞。
- 未去識別化的真實交易匯出檔。
- 含敏感個資的原始對話附件。
