# 需求清單

最後更新：2026-10-01

本文件記錄目前已知需求；內容不代表全部已正式定案。正式決策以 `DECISIONS.md` 為準。

## 訂單與付款

- 保存商戶單號、平台單號與上游單號。
- 保存建立時間、交易時間、付款結果時間、結算時間與下發時間。
- 保存商戶原始金額與幣別。
- 保存消費者手續費及消費者實付總額。
- 保存上游／通道交易金額及結算幣別。
- 包網可查詢訂單狀態。
- 本平台收到上游結果後，需可靠通知包網。
- callback 需簽章驗證、冪等、防重送副作用及重試機制。

## 狀態維度

- 付款狀態：等待、處理中、成功、失敗、拒絕、逾時等。
- 上游結算狀態：未結算、已結算、已沖正。
- 爭議狀態：無爭議、處理中、撤銷、成立、不成立、拒付等。
- USDT 下發狀態：不可下發、可下發、已入批次、處理中、已下發、失敗、待扣回。
- 風控狀態：未命中、黑名單拒絕、人工審查、人工放行。

## 商戶設定

- API Key／簽章密鑰與 IP 白名單。
- callback URL 與付款完成 redirect URL。
- 可用信用卡通道與優先順序。
- 交易幣別、結算幣別與交易限額。
- 消費者手續費設定。
- 商戶結算手續費設定。
- 所屬代理與商戶啟停狀態。

## USDT 商戶結算

- USDT 不設資金池，也不自動上鏈。
- 財務依日期、上游通道、商戶、代理及結算狀態篩選訂單。
- 只有符合資格的已結算訂單可加入下發批次。
- 建立下發批次時輸入 USDT 匯率並批次計算顆數。
- 批次建立後保存每筆訂單的金額、匯率與顆數快照。
- 財務人工付款後，記錄操作人、時間、地址快照、鏈別、交易雜湊或付款證明。

## 代理與佣金

- 代理有層級關係；目前討論傾向最多三層，仍待確認精確定義。
- 代理可建立查帳用子帳號。
- 代理相關費率異動需要總管理核准。
- 佣金以結算貨幣計算。
- 只有已下發訂單的佣金可以進入可結算狀態。
- 已下發後發生拒付時，需建立負向調整或由後續餘額扣回。

## 消費者手續費

- 每個商戶可設定不同消費者手續費。
- 付款確認頁須顯示訂單金額、消費者手續費與實付總額。
- 代理與代理子帳號的列表、統計、API 及匯出不得顯示此項費用。
- 管理與財務後台仍需保存並可對帳。
- 費率修改只影響生效後的新訂單，每筆訂單保存當時的設定快照。

## 爭議、沖正與黑名單

- 上游回傳交易失敗、沖正、舉報、非本人刷卡或其他原因時，系統保留原始狀態與訊息。
- 管理端可處理問題款項，但所有人工調整需記錄原因與操作者。
- 未下發前發生沖正時，取消可下發資格。
- 已下發後發生拒付時，產生負向帳務，不直接刪改原交易。
- 黑名單需支援卡片 token／fingerprint、遮罩卡號與持卡人姓名等條件。
- 對外只顯示客服錯誤碼，內部保存詳細拒絕原因。

## 權限與稽核

- 預留總管理、營運、客服、財務、風控、代理、代理子帳號與商戶角色。
- 權限同時控制功能與資料範圍。
- 敏感欄位的畫面、API、統計及匯出需一致限制。
- 關鍵設定、人工改單、批次結算及下發操作均需完整稽核紀錄。
